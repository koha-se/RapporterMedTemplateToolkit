# TemplateToolkit

Skapa en rapport i Koha

Lägg upp en ny Noticetext i Koha av typen "Rapport" 
Döp noticestexten till något om slutar med .html

Leta fram en befintlig lista i Koha och ta frma dess nummer
KÖr rapporten
Kör rapporten en gång till, men denna gång väljer du "Kör via nall"

OBS! Bokinfos bilder får bara användas om man har skrivit avtal med Bokinfo!
